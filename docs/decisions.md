# Chronological decision log

1. Literature review: choose infinite-thickness K–M, separate K and S, linear-light residuals; do not infer measured paint properties from RGB.
2. Exploratory Python implementations A/B/C precede Rust. `initial_midpoints.csv` and `initial_reconstruction.json` retain the first design (blue edge 500 nm, yellow edge 490 nm). A constant-S reconstructed spectrum made black+white (7,7,7); the initial hybrid yellow+blue was (19,128,145), too cyan for the intended example.
3. Edge sweep `edge_sweep.csv` varies synthetic blue and yellow passbands; choose yellow edge 530 nm and blue edge 510 nm as a compromise. Testing 530 nm for both gave a green but collapsed red+blue to black after residual correction and mapping; this is an observed negative finding, not a recommended model. Basis changes are artist-oriented priors, not measured pigment fitting.
4. Eight pigment classes retain W,C,M,Y,R,G,B,K. Four/five-pigment subsets are ablations, not assumed sufficient. Existence of multiple recipes is handled by a deterministic prior, not a claim of unique inversion.
5. Reference: 81 wavelength samples in f64. Fast: 21 samples in f32, tetrahedral 3D encoder LUT. Recompute the residual using the decoder actually used, so reduced spectral sampling and LUT interpolation do not create endpoint mismatch.
6. Rust constrained inversion is a projected Gauss–Newton solver with backtracking, weak regularization and fixed iteration budget. Python SLSQP is an independent exploratory solver; it is not a numerical oracle for a unique inverse, and recipes may differ. Cross-language forward checks use identical concentrations.
7. Performance will be reported separately for RGB calls and cached latent calls. The latter is the preferred brush-loop API. No extrapolation from desktop scalar results to GPU/WASM latency will be made.
8. The first Rust optimizer failed a canonical-hue test: a projected unconstrained Newton step can be a non-descent direction on a simplex boundary. It left substantial residuals and gave a cyan yellow-blue midpoint. Added projected-gradient fallback, retaining line-search acceptance; increased the iteration budget to 80. The corrected direct solver matches the independent SLSQP canonical recipes closely. This failure is retained as a methodological warning, not hidden by weakening the hue test.
9. Dense trajectory checks exposed a steep final approach to the blue endpoint (about 0.0216 encoded-channel change in the last 1/2000 interval of the diagnostic pair). This is a finite derivative/encoding issue, not a detected mathematical discontinuity: shrinking neighborhoods converge. Replaced an arbitrary channel-step threshold with a perceptual step bound plus a shrinking-neighborhood convergence test. The steep endpoint remains a recorded limitation; no time reparameterization is applied because it would alter the interpretation of concentration amounts.
