# Coefficient provenance and design choices

All new spectra are generated by `tools/optical_model.py`. The only external numerical inputs are the already attributed CIE 1931 2° and D65 tables in `data/cie_380_780_1nm.csv`; see `data/README.md` for origin, checksum and license. No Mixbox data or Spectral.js coefficients are read by generation. The new basis and derived integration arrays are distributed under the same CC BY-SA 4.0 attribution/share-alike notice as the underlying data assets; original implementation code remains MIT OR Apache-2.0. No new proprietary dataset is incorporated.

| Parameter | Origin and role |
|---|---|
| ε=0.001 | Chosen strictly positive reflectance floor and symmetric upper margin; prevents singular black/white optics while leaving a small correctable endpoint error. |
| Initial smoothing 0.01 | Bounded linear least-squares initialization. |
| Logit smoothing 0.001 | Selected from 0.0001, 0.001, 0.01, 0.03 after anchor and canonical diagnostics; larger values visibly reduced saturated-anchor fidelity. |
| β=0.5 | Geometric mean of neutral-luminance and per-band optical normalization. Selected compromise; β=0.25 retained more green-family chroma but shifted tint hues more. |
| White strength=2 | Explored 1, 2, 4. A modest, explicit relative optical-strength prior, not measured titanium-white scattering. |
| Reference 5 nm | 81 bands over 380–780 nm, retained as computational reference; interpolation-based 1 nm control is recorded. |
| Fast 10 nm | 41 bands; 20 and 40 nm had larger mixture discrepancies. |
| Color transforms | Published sRGB and OKLab definitions retained from v0.1; sources in research and math documents. |
| Solver tolerances | 1e−12 convergence tolerances and max_nfev=2000; authoring precision controls, not fitted optical parameters. |

`results/revision/generation.json` records all optimization status values and the exact basis SHA-256. `results/revision/basis_sweep.csv`, `optics_sweep.csv`, `candidate_validation.json` and `refitted_palette.json` preserve the explored alternatives, including failures. Configuration affects the generated code only after regeneration and recompilation. Coefficients are not manually maintained.
